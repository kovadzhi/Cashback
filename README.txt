Cashback prototype

Запуск: python3 -m http.server 8000 --bind 127.0.0.1
Открыть http://127.0.0.1:8000/
Для картографической подложки и MapLibre требуется интернет.

Экран реализован по Figma K42LmYaBCTN44DlHyMtPPL, секция 10:2642.
Header — 88 px; карта над списком — 570 px; над карточкой — 228 px.
На коротких экранах (<754 px) высота карты над списком адаптируется,
чтобы оставить для управления шторкой не менее 96 px.

Шторка списка: потяните за ручку вверх или вниз либо нажмите на неё.
Список содержит по одному предложению каждого партнёра из активной
области карты, включая предложения в кластерах. Сортировка — по весу
партнёра от большего к меньшему. При равенстве веса — по близости к центру.
Во время раскрытия списка его содержимое сохраняется: закрытие карты
шторкой не превращает найденные предложения в пустое состояние.
Категории пока отключены, как в задании.

Нажатие на пин или строку открывает карточку. Основная шторка сворачивается,
выбранный пин визуально центрируется в карте высотой 228 px.
Потяните заголовок карточки вверх для раскрытия; вниз — для сворачивания
или закрытия из активного состояния. Крестик и Escape закрывают карточку.
Закрытие восстанавливает исходный масштаб и центр карты.
Максимальная высота каждой шторки ограничена её содержимым и Header.

partners.js содержит категории и краткие описания 47 партнёров со ссылками
на источники. Адрес и условия акции одинаковы для всех и взяты из макета.
Логотипы партнёров сохранены из исходного прототипа. Иконки, градиент,
статусная строка и иллюстрация пустого состояния сохранены в assets/ из Figma.
Кэшбэк партнёра случайный (10–40%, шаг 5%) и постоянен до перезагрузки.
