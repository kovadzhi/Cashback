Cashback prototype

Запуск: python3 -m http.server 8000 --bind 127.0.0.1
Открыть http://127.0.0.1:8000/
Для карты и MapLibre требуется интернет.

Экран основан на Figma K42LmYaBCTN44DlHyMtPPL, секция 10:2642,
и дополнен правками поведения шапки и шторок от 5 ноября 2026.
Header — 44 px, без имитации system-status-bar. Картографический холст
занимает весь экран и виден под прозрачной шапкой. Активный вьюпорт
для пинов, списка и кластеризации — только между Header и шторкой:
570 px в исходном состоянии; 228 px при выборе предложения.
На коротких экранах карта адаптируется, оставляя для основной шторки 96 px.
Атрибуция MapLibre остаётся внизу полноэкранной карты под шторкой.

Шторки сначала раскрываются до максимума (ограниченного Header и высотой
контента) и только после этого разрешают прокрутку. Раскрывать можно за
ручку, за категории или жестом по содержимому; колесо/трекпад также сначала
раскрывает шторку. Продолжение свайпа вверх прокручивает содержимое только
после достижения максимума. Категории неактивны и остаются у Header при
прокрутке полностью раскрытого списка. Их можно потянуть вниз для сворачивания.
При стыке с Header шапка становится белой, ручка исчезает, скругления шторки
обнуляются; категории примыкают к Header. Dissolve — 300 ms.
Кнопки карты закреплены относительно исходной области карты: при раскрытии
шторки и выборе пина они растворяются за 300 ms, не меняя положения.

Список содержит по одному предложению каждого партнёра из активной области
карты, включая предложения в кластерах. Сортировка — по убыванию веса,
затем по близости к центру. При раскрытии список сохраняет найденные предложения.
Нажатие на пин или строку открывает карточку и центрирует выбранный пин.
Крестик, Escape и свайп вниз из активного состояния закрывают карточку.
Закрытие восстанавливает исходный масштаб и центр карты.

partners.js содержит категории, описания и источники для 47 партнёров.
Адрес и условия акции одинаковы для всех и взяты из макета.
Кэшбэк — случайный (10–40%, шаг 5%), неизменный до перезагрузки страницы.
Статические иконки, градиент и иллюстрация пустого состояния находятся в assets/.
